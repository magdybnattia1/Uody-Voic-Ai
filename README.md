# OUDI Voice AI

تطبيق أندرويد أولي للتحكم الصوتي باللغة العربية.

## المزايا المخطط لها
- واجهة عربية داكنة.
- استقبال أوامر صوتية بالعربية.
- التحكم في الفلاش.
- فتح إعدادات البلوتوث والواي فاي والإشعارات والمكالمات.

## البناء
افتح المشروع باستخدام Android Studio وانتظر مزامنة Gradle ثم اضغط Run.

ملاحظة: بعض إعدادات أندرويد، مثل انتظار المكالمات وإدارة إشعارات التطبيقات الأخرى، تتطلب صلاحيات خاصة أو تدخل المستخدم من صفحة الإعدادات.
